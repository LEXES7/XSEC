01 Built for the mistakes AI actually makes

    

      Assistants reach for whatever makes the demo work: string-built SQL, innerHTML,
      pickled payloads, keys pasted inline. XSEC's rules target exactly that pattern space.
    

    

      

        
⌖

        
Real static analysis

        
Python is scanned on the AST, JS/TS/Java with tree-sitter syntax awareness —
        so eval() in a comment doesn't page you, and SQL injection built from
        f-strings does.

      

      

        
⟁

        
Verified auto-fix

        
XSEC doesn't stop at reporting. Mechanical fixes are AST-precise; AI rewrites are
        gated by parse checks and a re-scan that proves the finding is gone — or the fix never
        touches disk.

      

      

        
◉

        
AI review, your choice of brain

        
Opt-in semantic review catches broken auth and unsafe data flow in any language.
        Use Claude for best quality or a free provider (Groq, OpenRouter) — keys live encrypted
        in your OS keyring.

      

      

        
⛁

        
Dependency CVE radar

        
Manifests and lockfiles — package-lock.json, poetry.lock,
        uv.lock — checked against the OSV database, covering every pinned transitive
        dependency.

      

      

        
⌗

        
Secrets that match reality

        
Provider-anchored patterns for AWS, GitHub, Stripe, Slack, Google, Anthropic and
        OpenAI keys — high precision, placeholder-aware, in every supported language.

      

      

        
⛨

        
Hardened & private by design

        
Runs fully offline by default. Input limits, no symlink following, ReDoS-resistant
        rules — XSEC treats the code it scans as hostile, because sometimes it is.

      A rewrite only lands when every gate passes.

03 Four engines, one finding format

    
Every engine emits the same Finding — so the console, JSON, SARIF, HTML report and the VS Code extension all work identically.

    

      

        SAST
        AST analysis for Python, tree-sitter for JS/TS/Java. Injection, deserialization, weak crypto, XXE, JWT bypass, SSRF surface, secrets.
        offline
      

      

        AI REVIEW
        Reads code like a senior reviewer — logic flaws, broken auth, unsafe flows. Concurrent & content-hash cached: re-scans only bill changed files.
        opt-in
      

      

        AUTO-FIX
        AST-precise mechanical rewrites plus verified AI rewrites. Safe fixes by default, behavior-changing ones behind a flag.
        offline*
      

      

        DEPS / CVE
        Manifests and lockfiles vs the OSV vulnerability database. Sends package names + versions, nothing else.
        opt-in
      

    

    
* mechanical fixes are offline; --ai-fix uses your chosen AI provider.
